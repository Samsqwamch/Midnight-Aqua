Install in Kodi

  1. Keep Estuary installed and back up your Kodi settings.
  2. Download the repository installer above. In Kodi, enable Unknown sources under Settings → System → Add-ons if needed, then choose Add-ons → Install from zip file.
  3. Choose the downloaded repository.midnightaqua-1.0.0.zip.
  4. Open Install from repository → Midnight Aqua Repository. Install Midnight Aqua Helper under Program add-ons, then Midnight Aqua under Look and feel → Skin.
  5. Select Midnight Aqua and confirm Keep. Restart Kodi. Enable optional helper features from the skin settings when desired.

For a Kodi file source, use https://samsqwamch.github.io/Midnight-Aqua/. The website address does not include /docs.

Global Search, Shadertoy, game clients and providers are optional and installed separately. Freedoom game data is not included here.

About this packaging revision

Skin 0.3.2 adds the Estuary redistribution notices and corrects license metadata. The skin interface, artwork and functionality match the supplied 0.3.1. The helper is unchanged.

The skin ZIP also contains its editable XML source. Downloads are hosted on GitHub Releases because the skin exceeds GitHub's regular file-size limit.
